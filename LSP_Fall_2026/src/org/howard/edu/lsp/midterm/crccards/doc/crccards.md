Library works with Book because almost everything Library is responsible for, like adding books, finding books, lending them, and searching for them requires it to hold Book objects and use their methods. Book does not need to work with Library because its only job is to retain information about the books, and whether it is available. Keeping this connection this makes Book simpler an easier to reuse. Library owns and enforces the three-book limit because it is a rule about all the books together, not a specific about one book. Since enforcing the limit is one of Library's responsibilities on its CRC card, library checks the limit first and then tells Book to change its own status.
